# SHINYURIGAOK — Travel & Tourism Website

Premium static website using Midnight Gold: #17243D, #D6B36A, #FFFFFF.

## Pages
Home, Destinations, Experiences, About, Contact, FAQ, Privacy, Terms.

## How to preview
Open `index.html` in a browser. All pages work locally; images and Google Fonts need an internet connection.

## GitHub Pages
Upload all files and the `assets` folder to your repository root. In Settings > Pages, choose Deploy from a branch, `main`, `/ (root)`.

## Demo disclosures
Prices are illustrative. There is no booking or payment processing. The contact form does not transmit messages.
